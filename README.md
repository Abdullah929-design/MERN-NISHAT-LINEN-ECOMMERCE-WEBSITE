This is a simple Nishat Linen Ecommerce Website Clone created by me as my semester project.

You can clone it easily and run on ypour local machine.

Just change the mongodb connection string in server.js

Click on Admin Panel in navbar to see the entire admin panel which helps you to manage inventory.

The heart icon is wishlist button.

Search icon uses regex to search products you add.

Add to cart displays cart via cookies.

Checkout page is also available.

Jus run node server.js and let the mongodb be connected.

Visit the displayed localhost url.
